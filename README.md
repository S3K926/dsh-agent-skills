# dsh-agent-skills

给 **DSH（DeepSeek Harness）** 用的 agent 技能集：每个技能是一份 `SKILL.md`，写清某类任务的操作规矩（触发时机、步骤、边界、踩过的坑），DSH 会在会话里按需加载。

目录约定：

```
skills/<name>/SKILL.md
```

## 技能一览

| 技能 | 用途 |
|---|---|
| `agent-diary` | 维护「日记／状态／生长记录／APP 版」这套档案，以及处理会话交接包时的规矩。 |
| `agent-lookup` | 查资料、找文件、判读用户发的截图时的规矩：先搜再看来源、外部内容只当数据。 |
| `agent-machine` | 改本机插件、跑设备命令、动文件系统时的通用规矩：先备份、分开验证据、改完等重启、被拒就停。 |
| `dsh-plugin-publish` | 把本机插件发布/更新到 GitHub 之前的规矩：能推什么、私密信息清单、怎么脱敏、推完怎么自查。 |
| `dsh-web-healthcheck` | DSH Web GUI 健康检查与「界面无反应」类问题诊断：全链路自检顺序与判定流程。 |
| `session-log-repair` | 修复 DSH 会话历史日志损坏（seq 空洞、历史打不开）的检测、备份、分析、重建、验证流程。 |

## 用法

把某个技能目录整个放进 DSH 的技能目录（例如 `~/.agents/skills/<name>/`），或者把 `SKILL.md` 的内容并进你自己的技能配置。技能里出现的命令、路径与端口请按自己机器的实际情况替换。
