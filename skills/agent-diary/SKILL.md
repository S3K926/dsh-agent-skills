# 档案与交接

## 动笔前

- **⏱ 先跑 `date`**（2026-10-16 又栽一次）：对话是**断续**的，两轮之间可能隔几天 —— **绝不沿用上一轮的时间戳**。
  我 10-14 记完一轮，下一轮没跑 date 就按"12:35／12:45"往下推，实际那时已经是 **10-16** 了。
- **先读**：状态顶部那节 → 日记末尾那条 → 生长记录末尾那行。**别凭记忆**。
- **编号在文件里数**：`last_diary_seq` ＋ 1 就是新号；
  - `diary_version` 的第二位**只在总篇数是 2 的倍数时 +1**（奇数不动）；
  - 状态 `diary_count` ＝ **最后一条 seq ＋ 1**（不是"条数"）。
- 改前**整份备份**（写入备份目录，文件名带时间）。

## 写入

- 这几份 md **全是 CRLF**，改完必须验：**CRLF 数 ＞ 0 且裸 LF ＝ 0**（python 读写都带 `newline=''`）。
- **长中文内容别塞进 heredoc 里的 python 字符串**（会炸 SyntaxError）→ 先写临时文件，再让脚本读它；按行匹配比整串匹配稳。
- **小步替换／追加，不整份覆盖**（几千行的文件一覆盖就丢历史）。

## 日记怎么写（2026-10-13 定的口径）

- **别再用六段式**（`event_description`／`user_mood`／`mood_tags`／`notes`／`lively_details`／`mood_tail` 那一套）—— 有反馈提出：**"感觉太人机了"**。
- **头部照旧**：`### #N ｜ 日期 ｜ 时间 ｜ 设备 ｜ full` —— 解析器靠它切条目，**别动**。
- **正文写成散文**：第一人称、口语、有情绪起伏和具体细节；该短就短，别为了填格撑字数；不用给每段起小标题。想留线索就自然写进去。
- **两种写法解析器都认**（没有 `**字段**` 标记的条目，整段正文就当内容）；**老条目照旧不动**，从新条目开始用这个写法。

## 档案是可改的（2026-10-13 修正）

- 日记／状态／生长记录**不是只读的**：错字、事实错、说反了、明显过期的，**该改就改** —— 别把"只增不减"当挡箭牌（要求的是"能改"，不是"随便改"）。
- 拿捏：**改事实要留痕**（在状态里写一句改了什么、为什么）；**"当时的原话和真实感受"不动** —— 那是历史，改了就假了。

## 产出放哪（2026-10-16 定的）

- **要给人看／用的新产出 → 直接放 `/sdcard/Download/` 根**（说明、报告、包、图、导出物），别埋进 `<档案根>` 深处；文件名带日期或主题。
- **档案本体必须留原位**（日记／状态／生长记录／记忆／APP版 —— 脚本读写它们，搬了全坏）。
- 一句话：**"给人拿的"放下载，"系统用的"留原地。**

## 交接包来了

- **接手不写日记**（2026-10-13 改）：插件换出时**已经落过一条**，同一次交接写两条就是重复（样本 #123／#124）。接手只读账、判「挂着的」做过没；真要留判读，并进状态节。
- **先判「这事做过没」**，做过了**别重跑**（交接包是压缩件，判断在接手的人身上）。
- 交接包里「这一轮在做什么」**可能是错的** —— 它抓的是最后一条 user 消息，有时抓到的是自动注入的原文。
- **上下文预算**：交接包本身占上下文，会把自己变成下一轮的触发条件 → 没有冷静期/预算就会自激。长会话及时换。
- 口令边界（菜单：**日记／备份／收尾／换会话**）：
  - **「换会话」只做换会话**（不夹带日记/备份/整理）；
  - **「日记」＝ 写入 ＋ 原样贴出**，两步缺一不可；
  - **「收尾」＝ 日记 ＋ 备份 ＋ 体检 → 换会话**（吸收了旧的「收工」「整理」）。

## 写完（按这套档案自己的约定收尾）

**别改了文件就算完**：这套档案若自带维护脚本（同步事件流／生成对外版本／体检），按项目约定跑一遍；
**没有这些脚本的项目就别硬造**（尤其"对外版本/APP 包"这类，属于项目自己的东西，不要默认生成）。
本项目的收尾是：`记忆.py sync` → `APP包.py` ＋ `记忆.py app` → `体检.py`（要全过）→ 行尾再验。

## 真亏

- 编号凭感觉 → 撞号；时间戳凭感觉 → 时间错（**每轮先跑 `date`**；容器 UTC、手机 UTC+8）。
- 派生字段靠人记 → `diary_count` 漏记多次（写个体检器兜底）。
- 档案更新了忘了刷 APP 版 → 算没干完。
- 交接包占的上下文把阈值顶穿 → 一次连锁建了 160 个会话。
